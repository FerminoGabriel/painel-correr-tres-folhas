# Painel de correr - tres folhas

Modelo3D independente do painel de correr do projeto Luciana e Luciano.

Inclui arquitetura recortada, laje de vigotas e EPS, forro, guias inferiores, trilhos superiores ocultos e animacao das folhas.

A viga e as ligacoes sao propostas geometricas sem capacidade resistente verificada. O dimensionamento depende do peso das folhas de aluminio e do levantamento das vigas de concreto existentes.

O projeto original e o site Conjunto suspenso nao foram alterados.
